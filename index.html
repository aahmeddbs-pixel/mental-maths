📋 How it works: the host creates a room and reads out the 5-letter code. Everyone types the code on their own device. When the host presses Start, a 3-2-1 countdown begins on every screen and everyone gets the same 100 questions. After every 5 questions, all players see the same ranking: 🎯 most correct and ⚡ fastest. You have 20 seconds per question, with no pausing and no skipping.
The host's level and answer settings are used for everyone.
